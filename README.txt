PHYSICA LAB — WEBSITE NHIỀU TRANG

CẤU TRÚC
- index.html                 Trang chủ
- dao-dong.html              Mô phỏng dao động điều hòa
- con-lac.html               Trang điều hướng khu thí nghiệm
- muc-tieu.html              Mục tiêu và dụng cụ
- quy-trinh.html             Các bước tiến hành
- mo-phong.html              Mô phỏng con lắc đơn
- so-lieu.html               Bảng số liệu có thể chỉnh sửa, xuất CSV
- do-thi.html                Đồ thị T² theo L và phân tích
- ly-thuyet.html             Thư viện công thức
- assets/css/style.css       Giao diện dùng chung
- assets/js/*.js             JavaScript tách riêng theo chức năng

CÁCH MỞ
1. Giải nén file ZIP.
2. Mở thư mục physica_lab_pages.
3. Nhấp đúp index.html để chạy website bằng Chrome/Edge.
4. Không đổi tên hoặc di chuyển riêng các file HTML/CSS/JS; giữ nguyên thư mục assets.

Website chạy cục bộ, không cần cài đặt và không cần Internet.
